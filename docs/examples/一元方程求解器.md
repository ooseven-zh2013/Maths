# 示例：做一个一元一次至四次方程求解器

面向**第一次用这个库写程序**的人。全程假设你只做一件事：解一元 n 次方程（n ≤ 4）。

- **目标程序**：`apps/polynomial/main.cpp`（本仓库里已 gitignore —— 这是练习，
  你自己写一遍比我给你看有用。下面每一步都告诉你该写什么、不给成品代码）
- **它的测试**：`tests/apps/polynomial/test_polynomial.cpp`（同样 gitignore）
- 配套程序 `apps/simplify` 是完整可读的参照实现，想看「成品长什么样」可以读它

---

## 第 0 步：先把「公式法」的边界搞清楚

**这一步最重要，跳过它后面全会走偏。**

| 次数 | 有公式吗 | 实际可行性 |
| --- | --- | --- |
| 1 | 有 | `x = −b/a`，一行 |
| 2 | 有 | 求根公式 + 判别式 Δ |
| 3 | 有 | Cardano（三次方根，含三角形式） |
| 4 | 有 | **六个分支的怪公式，实践中没人用** |
| 5 | 一般**没有** | Abel–Ruffini 定理（1824）：不存在根式通解 |

所以「解一元一次到五次」如果理解成「套公式」，**第五次是数学上做不到的**，不是「暂时没做」。

**但这不影响你的程序**：这个库给出的根不是浮点近似，而是**实代数数** ——
一个最小多项式加一个隔离区间，也就是「x⁴−2 的、在 [1.1892, 1.1893] 里的那个唯一正实根」。
这件事对任意次数都成立，1 到 4 次通吃。

于是本示例的设计是：

- **1~3 次**：给出教科书公式（让人看懂这题怎么解）+ 精确根
- **4 次**：明说「公式没人用」，直接给精确根
- 全程**精确**，不是浮点近似

## 第 2 步：先拿到「解析」这件事

**不要自己写表达式解析器。** 库里有：

```cpp
parseExpression("x^3-2x-5")   // → Result<RationalFunction>
```

拿到的是**多元**的有理函数（变量可以是 x、y、…），你要的是一元的，所以转一下：

```cpp
const Result<RationalFunction> parsed = parseExpression(line);
if (parsed.isErr()) {
  return Result<UnivariatePolynomial>::err(parsed.unwrapErr());
}
const std::optional<UnivariatePolynomial> asUnivariate =
    toUnivariatePolynomial(parsed.unwrap().getNumerator(), Variable("x"));
```

**两个坑**（新手几乎必踩）：

1. `toUnivariatePolynomial` 返回 `std::optional` —— 输入含 y 时给 `nullopt`，**不是错误码**
2. 要检查分母：`x²−1 / (x−1)` 不是多项式。`Polynomial` 没有 `constantTerm()`，
   但判「有没有变量」就够：`!denominator.variables().empty()` ⇒ 拒绝

## 第 3 步：拿到「根」—— 这是库给你的最大礼物

```cpp
const std::vector<RealAlgebraicNumber> roots = RealAlgebraicNumber::realRoots(polynomial);
```

一行解决全部问题。契约（`docs/src/numeric/algebraic_number.md` 有详细说明）：

- **升序**
- **互不相同**（重根只出现一次）
- 每个根带一个**隔离区间**：区间里只有这一个根

### ⚠️ 隔离区间一开始是**粗的**

```cpp
const Fraction low  = root.lowerBound();   // √2 可能是 [−3.75, 3.75] 这种
const Fraction high = root.upperBound();
```

要更紧的区间得自己调 `refine()`（它把区间折半，每调一次多一位精度）：

```cpp
RealAlgebraicNumber refined = root;        // refine 会就地改区间，所以用副本
for (int i = 0; i < 40 && !refined.isRational(); ++i) {
  refined.refine();
}
// 现在 [low, high] 已经能印 12 位小数了
```

### 怎么判断「这个数是有理数还是无理数」

```cpp
if (root.isRational()) {
  root.toFraction().unwrap()     // ← 无理数上调用会 Err，务必先判
}
```

### 怎么**精确验证**「r 确实是 p 的根」

⚠️ **不能**写 `polynomial.evaluate(root)` —— `UnivariatePolynomial::evaluate` 收的是
**有理数**，而无理根是代数数。用隔离区间两端异号：

```cpp
bool straddles(const UnivariatePolynomial &p, const RealAlgebraicNumber &r) {
  return (p.evaluate(r.lowerBound()) < Fraction(0, 1)) !=
         (p.evaluate(r.upperBound()) < Fraction(0, 1));
}
```

这是**精确**的验证（不是「约等于 0」）：区间里只有一个根，两端异号就说明区间里有根。

## 第 4 步：输出 —— 分三种形态，别混

`RealAlgebraicNumber` 给你两种渲染，各有用途：

| 方法 | 用途 | 例 |
| --- | --- | --- |
| `latex()` | **给人看的精确形式** | `\sqrt{2}`、`\frac{1}{2}` |
| 十进制 | 给不想看根式的人 | `1.414213562373` |

十进制是从隔离区间端点算的（`Fraction` 有 `operator double()`）：

```cpp
std::ostringstream out;
out << std::fixed << std::setprecision(12) << static_cast<double>(fraction);
```

⚠️ **终端输出里不要出现 LaTeX 命令**。`\quad`、`\\` 这类是排版命令，印在终端上是噪音
（仓库里踩过这个：分支分隔符本来用 `;\quad`，用户提出来后改成了 `;`）。

## 第 5 步：写测试（**别跳过**）

### 测试放哪

```
tests/
├── check.hpp              ← 共用的断言工具
├── core/                  ← 对应 src/core/*    （maths.core:*）
├── numeric/               ← 对应 src/numeric/* （maths.numbers 等）
├── algebra/               ← 对应 src/algebra/* （maths.algebra:*）
├── parser/                ← 对应 src/parser/*  （maths.parser）
└── apps/
    └── polynomial/        ← 对应 apps/polynomial/
```

**规则：`tests/` 的目录结构镜像 `src/`。** 测哪个模块就放对应位置，找测试不用全局搜。

`mcpp test` 会**自动发现** `tests/**/*.cpp`，一个文件一个可执行文件，**不需要登记**。

> 子目录里的 `#include "check.hpp"` 要写成 `#include "../check.hpp"`（相对路径）。

### 断言工具（`check.hpp`）

```cpp
CHECK_TRUE(条件)                    // 条件成立
CHECK_EQ(实际, 期望)                // 相等
CHECK_OK(表达式)                     // Result 应当是 Ok
CHECK_ERR(表达式, MathsError::X)    // Result 应当是 Err 且错误码是 X
TEST_SUMMARY();                     // 每个测试文件末尾必须有
```

`TEST_SUMMARY()` 会在失败数非零时返回非零码 —— CI 才认得出失败。**别漏。**

### 关键：**交互只是外壳，把逻辑抽出来就能测**

新手常见的误解是「程序要人敲键盘才能测」。不是 —— 解析、判次数、给公式、找根
都是**纯函数**，直接调：

```cpp
// 复制 app 里的纯函数到测试文件（本示例为了自包含这么做；真实项目应抽成头文件共用）
Result<UnivariatePolynomial> readPolynomial(const std::string &line) { … }
std::vector<RealAlgebraicNumber> rootsOf(const std::string &line) { … }
```

如果你的程序把逻辑埋在 `main()` 里或和 `std::cout` 缠在一起，**那才是「只能手动点」的原因** ——
该做的第一件事是把逻辑抽出来。

### ⚠️⚠️ 一个真实踩过的坑：**下标之前先看 size()**

写这个测试时我断言「`x³−2x−5` 有三个实根」，然后顺手写了 `roots[1]`。
但它的判别式 Δ₀ = −4p³−27q² = 32−675 = **−643 < 0，只有一个实根** ⇒
`roots.size() == 1` ⇒ `roots[1]` **越界访问 vector** ⇒ 未定义行为
⇒ 测试二进制 abort（`0xC0000409`），**一行断言信息都没打印**。

两个教训：

1. **`vector::operator[]` 不做检查**，越界是 UB 不是异常。永远先 `size()`。
2. 崩在断言之前的 UB 会**吞掉所有输出** —— 看起来像「测试没跑」，其实是崩了。
   遇到「测试毫无输出地失败」，先怀疑 UB。

### 建议的测试清单

| 类别 | 例子 |
| --- | --- |
| 解析：正常输入 | `x^2-2`、`2x+1`、`x^2 - 2*x + 1`（有空格）、`-x^3+1`（负首项） |
| 解析：该拒的 | `x+y`（非一元）、`x+`（语法错）、`(x^2-1)/(x-1)`（分母带变量） |
| 边界 | `0`（零多项式）、`5`（常数） |
| 一次 | `2x-4` ⇒ 根是 2 |
| 二次 | `x^2-3x+2`（两有理根）、`x^2-2x+1`（**重根只算一个**）、`x^2+1`（**无实根**）、`x^2-2`（无理根） |
| 三次 | `x^3-x`（三有理根）、`x^3-2x-5`（**只有一个**） |
| 四次 | `x^4-1`（两实根）、`x^4-2`（无理根） |
| 契约 | 根**升序**、**互不相同**（`(x-1)^2*(x-2)^3` 只有 2 个根） |

## 第 6 步：把「公式」那部分写清楚

公式是**给人看懂这题怎么解**的，精确值一律由 `realRoots` 给。两者分开写是有意的。

| 次数 | 公式 |
| --- | --- |
| 1 | `x = −b/a` |
| 2 | `Δ = b²−4ac`；Δ>0 两实根、Δ=0 重根、Δ<0 无实根 |
| 3 | 先除以 a 化成首一形式，令 `p = c/a − b²/(3a²)`、`q = 2b³/(27a³) − bc/(3a²) + d/a`，<br>则 `x = −b/(3a) + ∛(q/2 + √(q²/4+p³/27)) + ∛(q/2 − √(q²/4+p³/27))` |
| 4 | **不给** —— 只说明「有公式但没人用」 |

取系数用 `polynomial.coefficient(power)`（⚠️ 叫 `coefficient` 不是 `coefficientOf`，
且**升幂存储**：第 0 项是常数）。

### ⚠️ `Fraction` 的除法返回 `Result`

```cpp
Fraction operator/(const Fraction &) const;   // 返回 Result<Fraction>！
```

它要做零除检查。所以**任何 `/` 右边是有理数的除法**（哪怕 `/3`）都返回 `Result`：

```cpp
const Fraction bOverA = (b / a).unwrap();   // 这里可以放心 unwrap
```

为什么能放心：`a` 是首项系数，而 `a ≠ 0` 是「次数 = n」的**定义** —— 否则这个多项式
次数就不是 n 了。分母是具体非零常数时同理。

另外 `Fraction` **没有 `str()`**，它靠 `operator<<`：

```cpp
std::string fractionText(const Fraction &value) {
  std::ostringstream out;
  out << value;
  return out.str();
}
```

## 延伸

| 想做什么 | 去看 |
| --- | --- |
| 换个表示（代数系数、套嵌根号、绝对值） | `maths.value` 的 `Expression::parse` —— 一个入口，内部自动选表示 |
| 多元方程 | 库的多元部分（`maths.algebra:rational_multi` 等）；注意多元的符号判定需要 CAD 那套工具 |
| 复数根 | **本库不支持** —— `realRoots` 只给实根，且根的隔离区间概念只对实数成立 |
| 区间上的根 / 不等式 | `maths.real_set` 的 `RealSet::solve` |
