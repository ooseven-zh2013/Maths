# simplify — 交互式表达式化简

对应 `apps/simplify/main.cpp`。

## 运行

```bash
mcpp run simplify
```

## 流程

单趟、非循环 REPL：

1. 打印语法说明
2. 读一个**式子**（解析失败会重试，不会退出）
3. 式子含变量 → 打印条件说明，逐条读**条件**，输入 `0=0` 结束
   式子不含变量 → **跳过整个条件输入**，直接出结果（可以当计算器用）
4. 打印结果
5. 等一个回车后退出（双击运行时窗口不会立刻关闭）

```
式子: (x^2 - 1)/(x - 1)
条件> x = 2
条件> 0=0

--- 结果 ---
式子: \frac{x^{2} - 1}{x - 1}
条件:
  x = 2
化简结果: 3
常数结果: 3
```

## 语法

| 项 | 说明 |
| --- | --- |
| 运算 | `+ - * / ^` 与括号 |
| 变量 | 单个字母可带下标 —— `x`、`a_1`、`x_{i,j}` |
| 长名 | 多字母变量加花括号 —— `{node}`、`{node}_{car}` |
| 乘法 | 可省略 —— `xy` 即 `x*y`，`2x` 即 `2*x`（所以 `{node}` 不写花括号会变成 `n*o*d*e`） |
| 写法 | 普通写法与 LaTeX 写法都接受 —— `\frac{a}{b}`、`\cdot`、`\times`、`\div`、`x^{2}` |
| 根号 | `\sqrt{2}`、`\sqrt[3]{2}` —— **只接受 LaTeX 写法**（`√2` 与 `sqrt(2)` 都不认）|
| 有理指数 | `2^{1/2}` = `√2`、`2^{-1/2}`、`2^{\frac{1}{2}}`；变量底的分数指数（`x^{1/2}`）不支持 |

输出一律采用 LaTeX。解析规则详见
[expression_parser.md](../src/parser/expression_parser.md)。

## 根号能出现在哪

式子里的根号有两种含义，程序按「根号包的是数还是变量」分流：

| 位置 | 例子 | 结果 |
| --- | --- | --- |
| 式子里（根号包的是**数**） | `\sqrt{2}*x`、`x + \sqrt{2}`、`\sqrt[3]{2}*y` | ✅ 根号当**系数**处理 |
| 条件右边 | `x = \sqrt{2}`、`s = \sqrt{5}*t` | ✅ 条件的值可以是代数数 |
| 式子不含变量（当计算器） | `\sqrt{2}*\sqrt{2}` → `2`、`2^{1/2}` → `\sqrt{2}`、`\sqrt{2}+\sqrt{2}` → `\sqrt{8}` | ✅ 直接给精确值 |
| 根号包的是**变量** | `\sqrt{x}`、`\sqrt{x^2+1}`、`\sqrt{x}+\sqrt{x+1}` | ✅ 按函数域精确计算（条件要给有理数取值）|
| 根号包变量、但被开方数是**完全平方** | `\sqrt{x^2}`、`\sqrt{(x+1)^2}` | ❌ 开方结果带绝对值 `\|x\|`，本库不引入 `\|x\|` |

拒绝的两条都**明确报错**，绝不给近似值：

| 输入 | 提示 |
| --- | --- |
| `\sqrt{x^2}` | 无单一实根：主根是 `\|x\|`，本库不引入绝对值 |
| `\sqrt[3]{x}` | 只支持二次根（含变量的高次根需要更大的结构）|
| `\sqrt{x}+\sqrt{y}` | 被开方数必须含同一个变量 |
| `\sqrt{x}+\sqrt{4x}` | 多个根号落在同一平方类，请先化成最简根式 |
| `√2`（用了 Unicode 根号） | 提示改写成 LaTeX：`根号请写 \sqrt{2}`，因为 `√` 的结束位置没有公认约定 |
| `sqrt(2)` | 会被当成 `s·q·r·t·(2)`（隐含乘法），提示改用 `\sqrt{2}` |
| `2^{1/0}` | `分母不能为零` |
| `(-4)^{1/2}` | `负数不能开偶次根` |

**不做最简根式化**：`2\sqrt{2}` 显示成 `\sqrt{8}`，两者数值相等且都精确。

## 条件

写法是 **变量 = 表达式**：

| 输入 | 结果 |
| --- | --- |
| `x = 2` | 记录 |
| `s = v*t` | 记录，右边可含式子里没有的变量 |
| `x = x` | **删掉**变量 x 的约束（重复输入同名变量则是覆盖） |
| `0=0` | 结束输入 |
| `x = 2x` | 不接受 —— 右边含被赋值的变量本身，那是方程 |
| `2 = 2` | 跳过 —— 恒等式，没有可记录的信息 |
| `2x` 配 `s = v*t` | 跳过 —— 与式子和已有条件都无关 |

输入 `x = x` 时若该变量本来就没有约束，提示「跳过 · x 本来就没有约束」。

## 结果区

| 字段 | 出现条件 |
| --- | --- |
| `式子` | 总是 |
| `条件` | 总是；无条件时列一行「（无）」 |
| `无法代入` | 代入后分母为零 —— 那是原式的**极点**，不是程序错误，程序正常结束（退出码 0） |
| `化简结果` | 代入成功后 |
| `可化为多项式` | 长除法能整除**且分母不是常数** |
| `常数结果` | 分子分母都能化为常数 |
| `精确值` | 式子是**纯数值**（可含根号）时；先过 `toFraction()` —— 值是有理数就写成分数，否则回退 `latex()` |
| `定义域` | 式子里含**带变量的根号**、且定义域不是整条实轴时（`√x` → `[0, +\infty)`、`1/√x` → `(0, +\infty)`）|
| `注意` | 化简中约去了变量 |

### 「可化为多项式」为什么要求分母非常数

这一行的目的是**补定义域**：长除法归约会丢掉「原式在分母零点处无定义」这一信息，
所以输出时附带「（原式要求 ⟨分母⟩ ≠ 0）」。

常数分母恒非零，没有零点可丢，报出来只是把化简结果再抄一遍
（`5/6` 会被报成「可化为多项式: `\frac{5}{6}`」，零信息量）。

```
式子: (a^2-1)/(a+1)
条件> a = 2

--- 结果 ---
化简结果: 1
```

```
式子: (a^2-1)/(a+1)

--- 结果 ---
化简结果: \frac{a^{2} - 1}{a + 1}
可化为多项式: a - 1（原式要求 a + 1 \neq 0）
```

第二个例子没给 `a` 的值，所以归约后的分母零点信息需要显式补出来。

## 输出的行式规范

这个程序的输出曾经是「加一个功能就加一句提示」，措辞、缩进、标点各不相同
（`忽略: xxx`、`恒等式，无需记录`、`与式子无关，不记录` 三种说法其实是同一件事）。
现在收敛成四种行式，由 `printField` / `printListItem` / `printFeedback` 三个函数强制产出：

| 行式 | 格式 | 用途 |
| --- | --- | --- |
| 字段行 | `名字: 值`（从属时缩两格） | 说明与结果 |
| 列表行 | `  值` | 字段行下的同构项（如条件列表） |
| 反馈行 | `  动作 · 说明` | 回应一次输入 |
| 输入提示 | `式子> ` / `条件> ` | 与字段行的 `式子: ` 区分开 |

反馈行的动作词**只有五个**，不要自造：

| 动作 | 含义 |
| --- | --- |
| `已记录` | 输入被采纳，记下一条约束 |
| `已删除` | 输入被采纳，删掉一条已有约束 |
| `跳过` | 输入合法，但没有可记录的信息 |
| `不接受` | 输入无法采纳，后面接原因 |
| `提示` | 补充说明，跟在上面任意一条之后 |

**新增任何输出，先挑行式、再用那三个函数输出**，不要直接写 `std::cout` 拼字符串 ——
直接拼就是这套规范失效的开始。
