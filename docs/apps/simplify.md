# simplify — 交互式表达式化简

对应 `apps/simplify/main.cpp`。

## 运行

```bash
mcpp run simplify
```

## 流程

> 程序**不再打印语法说明** —— 用法类内容只留在本文档，app 只报结果与原因。

单趟、非循环 REPL：

1. 打印语法说明
2. 读一个**式子**（解析失败会重试，不会退出）
3. 式子含变量 → 打印条件说明，逐条读**条件**，输入 `0=0` 结束
   式子不含变量 → **跳过整个条件输入**，直接出结果（可以当计算器用）
4. 打印结果
5. 等一个回车后退出（双击运行时窗口不会立刻关闭）

```
式子: (x^2 - 1)/(x - 1)
条件> x = 2
条件> 0=0

--- 结果 ---
式子: \frac{x^{2} - 1}{x - 1}
条件:
  x = 2
化简结果: 3
常数结果: 3
```

## 语法

| 项 | 说明 |
| --- | --- |
| 运算 | `+ - * / ^` 与括号 |
| 变量 | 单个字母可带下标 —— `x`、`a_1`、`x_{i,j}` |
| 长名 | 多字母变量加花括号 —— `{node}`、`{node}_{car}` |
| 乘法 | 可省略 —— `xy` 即 `x*y`，`2x` 即 `2*x`（所以 `{node}` 不写花括号会变成 `n*o*d*e`） |
| 写法 | 普通写法与 LaTeX 写法都接受 —— `\frac{a}{b}`、`\cdot`、`\times`、`\div`、`x^{2}` |
| 根号 | `\sqrt{2}`、`\sqrt[3]{2}` —— **只接受 LaTeX 写法**（`√2` 与 `sqrt(2)` 都不认）|
| 有理指数 | `2^{1/2}` = `√2`、`2^{-1/2}`、`2^{\frac{1}{2}}`；变量底的分数指数（`x^{1/2}`）不支持 |
| 绝对值 | `|x|`、`|x+1|`、`|\frac{x}{x-1}|` —— 与 `\sqrt{x^2}` 是同一件事（见下）|
| 优先级 | 一元负号在 `^` **外面**：`\sqrt{-x^2}` 是 `-\sqrt{x^2}`（先幂后负号）；`x^2^3` 不接受 |

输出一律采用 LaTeX。解析规则详见
[expression_parser.md](../src/parser/expression_parser.md)。

## 被开方数是完全平方：分段函数

`\sqrt{x^2}` 的开方结果是 `|x|`。**它不是单个式子** —— 代数函数域里
`ℚ(x)[y]/(y²−g²)` 可约、`y` 是零因子、`±g` 都是根，没有单值元素，所以
`RadicalExtension` 明确拒收。

但 `|x|` 作为 `ℝ → ℝ` 的函数完全合法，只是需要**分段**才表示得出来。程序会把这类输入
接成**分段函数**：

```
式子> \sqrt{x^2}
  解析为: \begin{cases}x & x \in [0, +\infty) \\ -x & x \in (-\infty, 0)\end{cases}

--- 结果 ---
式子: \sqrt{x^2}
分段结果:
  \begin{cases}x & x \in [0, +\infty) \\ -x & x \in (-\infty, 0)\end{cases}
各支:
  x   当 [0, +\infty)
  -x   当 (-\infty, 0)
```

做法是把每个 `\sqrt{g²}` 换成临时变量、用正常的根式路径解析，再按 `g ≥ 0` / `g < 0`
分成 2<sup>k</sup> 支（k 是这类根号的个数，上限 4）。所以 `\sqrt{x^2}*\sqrt{(x-1)^2}`
给 3 支（符号冲突的那些支定义域为空，被丢掉）：

```
{ x²−x 当 [1,+∞) ; −x²−x 当 [0,1) ; x²−x 当 (−∞,0) }
```

这条路径**只支持一元**（分段函数本身就是一元的），也不走「代入条件」那一套 ——
分段函数的结果就是把分支摆出来。

## 套嵌根号：塔

`\sqrt{1+\sqrt{x}}` 这种**根号里还有根号**的式子，代数函数域装不下（`ℚ(x)[y₁,y₂]/(y₁²−f₁, y₂²−f₂)`
里两个生成元的关系互相依赖），所以走**塔**：由内往外逐个根号加一层。

| 输入 | 结果 |
| --- | --- |
| `\sqrt{1+\sqrt{x}}` | 深度 2，定义域 `[0, +\infty)`，配 `x = 4` → `\sqrt{3}` |
| `\sqrt{2+\sqrt{x}}` | 深度 2，配 `x = 4` → `2` |
| `\sqrt{1+\sqrt{x}}+\sqrt{3}` | 深度 3 |
| `1/\sqrt{1+\sqrt{x}}` | 深度 2，配 `x = 4` → `1/\sqrt{3}` |

塔只在**有理取值**的点上有值（条件右边可以写根号，但必须能化成有理数）——
这一点与代数函数域那条路不同，后者支持代数数取值。

**除法直接就是「分子 / 分母」**，不绕弯：`1/\sqrt{1+\sqrt{x}}` 显示成
`\frac{1}{\sqrt{1 + \sqrt{x}}}`，配 `x = 1` 得 `\sqrt{\frac{1}{2}}`

内部的塔元素就是「平表之比」，**分母本身也可以含根号** —— 与代数函数域那套一致。
（早先的版本分母被限制成有理函数，于是 `1/(1+\sqrt{x})` 在 `x=1` 处会算出 `0/0`；
那个限制已经去掉了。`1+` 类的前缀不再需要绕共轭。）

## 多元：变量不止一个

`\sqrt{x^2+y^2}`、`\sqrt{1+\sqrt{x^2+y^2}}` 这类式子走多元那一档。
**条件要给一个点**（一行多个赋值），不是一条一元约束：

| 输入 | 条件 | 精确值 |
| --- | --- | --- |
| `\sqrt{x^2+y^2}` | `x=3, y=4` | `5` |
| `\sqrt{1+\sqrt{x^2+y^2}}` | `x=3, y=4` | `\sqrt{6}` |

与一元那边不同的三点：

- 一行可以给多个条件（`x=3, y=4`），读满所有变量才算一个点；少给会报「还差 y」
  并**不算** —— 拿部分变量算出来的值没有意义
- 取值只接受**纯有理数**（多元塔只在有理取值的点上有值）
- 不给多元式子报定义域 —— 见下

⚠️ **多元式子没有定义域输出**。不是漏了，是给不出：`{fᵢ ≥ 0}` 里的 fᵢ 含生成元，
而约束式的多项式只能在 x、y 里；唯一的出路是把条件化归成多元多项式不等式，
而那需要柱状代数分解（CAD），本库不做。

## 绝对值：`|x|` 与 `\sqrt{x^2}` 是同一件事

绝对值的**内部形式就是 `√(g²)`** —— 而代数函数域装不下它（`ℚ(x)[y]/(y²−g²)` 可约、
`y` 是零因子、`±g` 都是根）。所以程序统一按「符号分段」计算，**输出时再把
`√(g²)` 那个结构还原成 `|g|`**：

| 输入 | 内部 | 输出 |
| --- | --- | --- |
| `\|x\|`、`\sqrt{x^2}` | 两支：`x` 当 `[0,+∞)`、`−x` 当 `(−∞,0)` | `\|x\|` |
| `\|x+1\|` | 两支，拐点挪到 −1 | `\|x + 1\|` |
| `\|2x-1\|` | 两支 | `\|2x - 1\|` |
| `\|\frac{x}{x-1}\|` | 两支；⚠️ 定义域在 `x = 1` 有洞，两支**不是互补** | `\|\frac{x}{x - 1}\|` |
| `\|x\|*\|x-1\|` | 三支（符号冲突的那些支定义域为空，被丢掉） | cases 块（不是 `\|g\|` 形状）|
| `\sqrt{x^2}+1` | 两支 | cases 块（同上）|

`g` 可以是**任意有理式**，不只是一个变量。两种写法走**同一条路**（`\|g\|` 先被改写成
`\sqrt{(g)^2}`），所以结果完全一致。

**能代入条件求值**：

```
式子> |2x-1|
条件> x = -3
  记录 x = -3

--- 结果 ---
式子: |2x-1|
条件:
  x = -3
分段结果: |2x - 1|
自变量: x
定义域: \mathbb{R}
各支:
  2x - 1   当 x \in [\frac{1}{2}, +\infty)
  -2x - 1   当 x \in (-\infty, \frac{1}{2})
精确值: 7
```

结果区**必给「自变量」与「定义域」**，各支的区间也写成「当 x ∈ …」而不是光秃秃一段区间 ——
区间是「在哪个变量上」的范围，不写出来读者得自己猜。

分段函数是**一元**的，所以只认它自己那个变量的条件；给别的变量会被判成「与式子无关」。

## 根号能出现在哪

式子里的根号有两种含义，程序按「根号包的是数还是变量」分流：

| 位置 | 例子 | 结果 |
| --- | --- | --- |
| 式子里（根号包的是**数**） | `\sqrt{2}*x`、`x + \sqrt{2}`、`\sqrt[3]{2}*y` | ✅ 根号当**系数**处理 |
| 条件右边 | `x = \sqrt{2}`、`s = \sqrt{5}*t` | ✅ 条件的值可以是代数数 |
| 式子不含变量（当计算器） | `\sqrt{2}*\sqrt{2}` → `2`、`2^{1/2}` → `\sqrt{2}`、`\sqrt{2}+\sqrt{2}` → `\sqrt{8}` | ✅ 直接给精确值 |
| 根号包的是**变量** | `\sqrt{x}`、`\sqrt{x^2+1}`、`\sqrt{x}+\sqrt{x+1}` | ✅ 按函数域精确计算（条件要给有理数取值）|
| 根号包变量、但被开方数是**完全平方** | `\sqrt{x^2}`、`\sqrt{(x+1)^2}` | ✅ 开方结果是 `\|x\|`，**按分段函数**给出（见上）|
| 式子**一元**且被开方数是完全平方 | `\sqrt{x^2}`、`\sqrt{x^2}*\sqrt{(x-1)^2}` | ✅ 展开成 2<sup>k</sup> 支（k 个完全平方的根号，上限 4）|

每个限制都有**专属错误码**，报出来的是「卡在哪」而不是笼统的「不支持」——
这样一眼能分清是自己写错了，还是碰到了库的能力边界。绝不给近似值。

| 输入 | 报什么 |
| --- | --- |
| `x*y+\sqrt{x^2}` | `不是一元函数（含多个自变量）` —— 分段函数是一元的 |
| `|\sqrt{ab}|` | `绝对值里面不能再带根号`（真写 `\sqrt{\sqrt{x}}` 才是「根号里不能再套根号」）|
| `\sqrt{ab}` | `根号里含多个变量` —— 根号只支持单变量 |
| `\sqrt{x}\sqrt{y}` | `根号里含多个变量`（被开方数必须含同一个变量）|
| `\sqrt{x^2}` 写五个以上 | 分支出数会爆（2⁵ 支），明确拒绝 |
| `\sqrt[3]{x}` | 只支持二次根（含变量的高次根需要更大的结构）|
| `\sqrt{x}+\sqrt{y}` | 被开方数必须含同一个变量 |
| `\sqrt{x}+\sqrt{4x}` | 多个根号落在同一平方类，请先化成最简根式 |
| `√2`（用了 Unicode 根号） | 提示改写成 LaTeX：`根号请写 \sqrt{2}`，因为 `√` 的结束位置没有公认约定 |
| `sqrt(2)` | 会被当成 `s·q·r·t·(2)`（隐含乘法），提示改用 `\sqrt{2}` |
| `2^{1/0}` | `分母不能为零` |
| `(-4)^{1/2}` | `负数不能开偶次根` |

**不做最简根式化**：`2\sqrt{2}` 显示成 `\sqrt{8}`，两者数值相等且都精确。

### 碰到限制时怎么改写

程序只报「卡在哪」，补救办法在这里：

| 原来 | 改写成 | 为什么 |
| --- | --- | --- |
| `\sqrt{x^2}`（x 无符号限制） | x ≥ 0 时直接写 `x`；否则写 `|x|` | `sqrt{x^2}` 就是 `|x|`，代数函数域装不下，分段才装得 |
| `\sqrt{x^2}\sqrt{(x-1)^2}` | 两边各自写成 `|…|` | 内部形式会套嵌 |
| `\sqrt{ab}`（a、b 都非负） | `\sqrt{a}*\sqrt{b}` | 根号不能跨变量 |
| `\sqrt{x}\sqrt{y}` | 先展开再合并同类项 | 被开方数必须含同一个变量 |
| `x*y+\sqrt{x}` | 分两次算 | 一元类型装不下两个自变量 |

## 条件

写法是 **变量 = 表达式**：

| 输入 | 结果 |
| --- | --- |
| `x = 2` | 记录 |
| `s = v*t` | 记录，右边可含式子里没有的变量 |
| `x = x` | **删掉**变量 x 的约束（重复输入同名变量则是覆盖） |
| `0=0` | 结束输入 |
| `x = 2x` | 不接受 —— 右边含被赋值的变量本身，那是方程 |
| `2 = 2` | 跳过 —— 恒等式，没有可记录的信息 |
| `2x` 配 `s = v*t` | 跳过 —— 与式子和已有条件都无关 |

输入 `x = x` 时若该变量本来就没有约束，提示「跳过 · x 本来就没有约束」。

## 结果区

| 字段 | 出现条件 |
| --- | --- |
| `式子` | 总是 |
| `条件` | 总是；无条件时列一行「（无）」 |
| `无法代入` | 代入后分母为零 —— 那是原式的**极点**，不是程序错误，程序正常结束（退出码 0） |
| `自变量` / `定义域` | 分段函数：自变量是谁、定义域是什么（各支的区间一律写成「当 x ∈ …」）|
| `分段结果` / `各支` | 输入被解析成**分段函数**时（`\|…\|` 或被开方数是完全平方）。`\|g\|` 形状只给 `分段结果` 一行 `\|g\|` |
| `精确值` | 分段函数代入条件后 |
| `化简结果` | 代入成功后 |
| `可化为多项式` | 长除法能整除**且分母不是常数** |
| `常数结果` | 分子分母都能化为常数 |
| `精确值` | 式子是**纯数值**（可含根号）时；先过 `toFraction()` —— 值是有理数就写成分数，否则回退 `latex()` |
| `定义域` | 式子里含**带变量的根号**、且定义域不是整条实轴时（`√x` → `[0, +\infty)`、`1/√x` → `(0, +\infty)`）|
| `注意` | 化简中约去了变量 |

### 「可化为多项式」为什么要求分母非常数

这一行的目的是**补定义域**：长除法归约会丢掉「原式在分母零点处无定义」这一信息，
所以输出时附带「（原式要求 ⟨分母⟩ ≠ 0）」。

常数分母恒非零，没有零点可丢，报出来只是把化简结果再抄一遍
（`5/6` 会被报成「可化为多项式: `\frac{5}{6}`」，零信息量）。

```
式子: (a^2-1)/(a+1)
条件> a = 2

--- 结果 ---
化简结果: 1
```

```
式子: (a^2-1)/(a+1)

--- 结果 ---
化简结果: \frac{a^{2} - 1}{a + 1}
可化为多项式: a - 1（原式要求 a + 1 \neq 0）
```

第二个例子没给 `a` 的值，所以归约后的分母零点信息需要显式补出来。

## 输出的行式规范

这个程序的输出曾经是「加一个功能就加一句提示」，措辞、缩进、标点各不相同
（`忽略: xxx`、`恒等式，无需记录`、`与式子无关，不记录` 三种说法其实是同一件事）。
现在收敛成四种行式，由 `printField` / `printListItem` / `printFeedback` 三个函数强制产出：

| 行式 | 格式 | 用途 |
| --- | --- | --- |
| 字段行 | `名字: 值`（从属时缩两格） | 说明与结果 |
| 列表行 | `  值` | 字段行下的同构项（如条件列表） |
| 反馈行 | `  动作 · 说明` | 回应一次输入 |
| 输入提示 | `式子> ` / `条件> ` | 与字段行的 `式子: ` 区分开 |

反馈行的动作词**只有五个**，不要自造：

| 动作 | 含义 |
| --- | --- |
| `已记录` | 输入被采纳，记下一条约束 |
| `已删除` | 输入被采纳，删掉一条已有约束 |
| `跳过` | 输入合法，但没有可记录的信息 |
| `不接受` | 输入无法采纳，后面接原因 |
| `提示` | 补充说明，跟在上面任意一条之后 |

**新增任何输出，先挑行式、再用那三个函数输出**，不要直接写 `std::cout` 拼字符串 ——
直接拼就是这套规范失效的开始。



**一行可以写多条**：`x=3, y=4` 与分两行完全等价。所有档（有理式 / 根式 / 分段 / 塔）
都这么收 —— 早先只有塔那一档收、其余档把整行当一条解析，于是同一句话在不同输入下
含义不同。

**多元的绝对值也支持**（`|x-y|`、`|x*y-1|`、`|x/y-1|`）：拆成 `{f ≥ 0}` 与 `{f < 0}` 两支，
各带一个区域，给值时点落在哪支取哪支。带分母也对 —— `g ≥ 0` 等价于 `分子·分母 ≥ 0` 且 `分母 ≠ 0`。

取值点和多元根号一样，**一次给全**：`x=3, y=4`。`y=0` 这类落在定义域外的点会明确报「不在定义域内」。
