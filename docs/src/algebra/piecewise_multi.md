# maths.algebra:piecewise_multi — 多元分段函数与多元绝对值

对应 `src/algebra/piecewise_multi.cppm`。一元的绝对值在 `maths.algebra:piecewise`。

## 分支是「规则 + 区域」，不是「规则 + 一维区间」

```cpp
struct Branch {
  MultiRule rule;   // 多元有理函数，或一条多元塔
  Region domain;    // 半代数区域（约束系统的析取范式）
};
```

与一元那版的两个差别：

1. **定义域是 `Region` 而不是 `RealSet`** —— `{x ≥ 0 ∧ y ≥ 0}` 与 `{x < 0} ∨ {y < 0}`
   都得有地方放，所以区域是 DNF 而不是区间的并
2. **分支两两不交** —— `at(point)` 按「点落在哪一支」选分支，重叠就是歧义。
   `make()` 会在支数 ≤ 8 时真去验，支数一多就跳过（交运算的支数会涨，穷举不现实）

## `|f|` 在多元里是能表示的

    |f|  =  { f : {f ≥ 0} }  ∪  { −f : {f < 0} }

**关键在于这不是「需要 CAD」**。两支的定义域就是符号本身写着呢 ——
表示与符号判定是两件事。而 `g = N/D` 的符号条件精确且廉价：

    g ≥ 0  ⟺  N·D ≥ 0 ∧ D ≠ 0        （同号；分母不能为 0）

全程只有多项式乘法。`parseMultiPiecewiseExpression("|x-y|")` 走的就是这条路：
先 `|g|` → `√(g²)`，再对每个「完全平方的根号」枚举 ±g，每支的 `Region` 是符号条件
与分母非零条件的合取。

只需要 CAD 的是**化简**（合并区域、判哪支是空集），那不做。

## 三条判读要点

**1. `admits(point)` 与 `at(point)` 分工不同** —— 前者只说「点在不在函数里」，
后者还要选出分支并求值。点不在任何支里时 `at()` 报 `OutsideDomain`。

**2. 判不出空性 ≠ 重叠。** `make()` 检查两支是否重叠时用 `isEmptyRegion()`，
而它在多元多项式不等式上判不出来时返回 `Err(DomainNotDecidable)`：

```cpp
const Result<bool> empty = overlap.unwrap().isEmptyRegion();
if (empty.isOk() && !empty.unwrap()) { /* 只有「能证明非空」才算歧义 */ }
```

⚠️ 这里**不能**写成 `if (!overlap.isEmptyRegion().unwrap())` —— 对错误结果 unwrap
就是 abort（0xC0000409），多元绝对值会必崩。判不出就放行：解析器造出来的分支
**按构造就互斥**（同一个多项式上一支要 `≥ 0`、另一支要 `< 0`）。

**3. `Region::variables()` 告诉 app 该问哪几个取值** —— 各支变量集合的并集。

## 渲染里两个容易踩的细节

- **恒真的原子不印**（`AtomConstraint::isTautology()`）。符号条件天然带一条
  `分母 ≠ 0`，而分母是 1 的情形（`|x-y|`）就是 `1 ≠ 0` —— 恒真，印出来是噪音。
  而 `|x/y-1|` 的 `y ≠ 0` **不是**恒真，必须留着。
- **分支分隔符不能用 `\\`**（LaTeX 的换行），用 `;\quad`。

## app 里的档位顺序

`parseMultiPiecewiseExpression` 放在**多元塔之后、一元分段之前**：

- 多元塔在前面 → `|√(x-y)|` 这种带根号的绝对值先被塔接走
- 一元分段在后面 → 它见多元会报 `NotUnivariate`，而**那个诊断只对「输入本该是一元」
  才有意义**。`|x-y|` 确实是多元，报「不是一元函数」是误导

## 已知限制（下面三条是**实测**的，2026-10-05）

app 里逐个试过：

| 输入 | 结果 |
| --- | --- |
| `\|x-y\|` | ✅ 拆成两支：`x - y` 当 `x - y ≥ 0`；`-x + y` 当 `x - y < 0`（分子是完全平方时短路成一支）|
| `\|\|x-y\|\|`（嵌套） | ❌ `不支持的表达式`（`InvalidExpression`） |
| `\|√(x²+y²)-1\|`（内层带根号） | ❌ `不支持的表达式` |
| `\|\|x\|-y\|` | ❌ `不支持的表达式` |

**能做的**：形如 `|f|`、`f` 是**多元有理式**的输入（可以有分母）。

**不能做的**：绝对值里再套绝对值，或绝对值里带根号。前者是分支枚举会指数增长
（`kMaxSquareRadicals` 卡在 4）；后者是内层要塔、外层要区域，两种表示对不上。

⚠️ 这三种目前都报 `InvalidExpression`，于是 app 显示「不支持的表达式」——
**没有说清是哪个表示装不下**。按项目自己的规矩（错误说明要写清「哪个表示装不下」，
别写成「本库不支持 X」），这里应该给专属错误码，是一条待补的诊断改进。
