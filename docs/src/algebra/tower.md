# maths.algebra:tower — 套嵌根式（塔）

对应 `src/algebra/tower.cppm`。多元那份是 `maths.algebra:tower_multi`（`MultiTowerExtension`），
两者结构平行，本文只讲一元。

## 它解决什么问题

`radical` 层能表示 `√(x²+1) + √(x²+2)`，但**表示不了根号里带根号**：

    √(1 + √x)          ← √x 的值依赖于 x，指数 1/2 不是有理数
    (1 + √x)^(1/3)     ← 指数是有理数，但底数含根号

代数函数域那条路（`ℚ(x)[y]/(y²−g)`）也不行 —— 当 `g` 不是常数时它是**可约**的，
`y` 会成为零因子，装不下这样的元素。

塔的做法是**把每个根号当成新的生成元**，一层层往上叠：

    √x        →  y₁² = x
    √(1+√x)   →  y₁² = x 、y₂² = 1 + y₁
    √(1+√(1+√x)) →  y₁² = x 、y₂² = 1 + y₁ 、y₃² = 1 + y₂

求值时逐层嵌套调 `nthRoot(2)`，**从最里层往外算**。

## 元素是「平表之比」

第 d 层的元素是 `ℚ(x)(y₁,…,y_d)` 里的有理函数，也就是两个**平表**（长度 2^d 的数组）
之比：

    分子 N   下标是掩码，掩码第 i 位 = yᵢ 的指数
    分母 D   同上

    例：d=2 时，(1 + y₂) / y₁ 的掩码分别是 0b0010 与 0b0001

**为什么要分母也做成平表** —— 这是 2026-10-04 那次重构的全部要点：

| | 旧表示（分母固定为有理函数） | 现在（平表之比） |
| --- | --- | --- |
| `1/(1+√x)` 的表示 | `c₀ = c₁ = 1/(1−x)` | 分子 `1`，分母 `1 + y₁` |
| 在 `x=1` 处 | **0/0**（可去极点） | `1/2` ✓ |
| 形态 | 要绕共轭有理化才好看 | `\frac{1}{1+\sqrt{x}}` 天然正确 |

关键在于**除法就是交叉相乘**：

    ÷ :  (N₁/D₁) ÷ (N₂/D₂) = (N₁·D₂) / (D₁·N₂)

旧表示下这个式子无解（元素只能表达 `c₀ + c₁y₁` 而 `1/(1+√x)` 超出这个空间），
当时是靠「解 2^d 维乘法矩阵」硬凑出一个**错的**表示 —— 顺带把那 60 行代码也删掉了。

## 三条红线

1. **被开方数必须平方自由** —— `√(2x)` 会自动扩成 `√2·√x`，不做最简根式化之外的化简
2. **各根号必须平方类独立** —— 报 `RadicalsNotIndependent`，因为 `√x·√x = x` 会破坏
   「生成元是独立代数元」的前提
3. **多元的嵌套根号不做** —— `√(1+√(x²+y²))` 里内外两个被开方数耦合，
   塔的逐层嵌套调不再适用

## 求值

`evaluate(Scope)` 逐层算：第 i 层先算 `relations_[i]`（它是**前 i−1 个**生成元的表达式），
非负就调 `nthRoot(2)`，然后把结果压进 `generators` 供上层用。最后分子 ÷ 分母，
分母为 0 报 `ZeroDenominator`。

**符号判定**（`whereNonNegativeOverTower`）走的是一元那套：把 2^(d+1) 个乘积算出来，
若有一个是非零常数，符号由它定；否则报 `DomainNotDecidable`。

⚠️ 它**先问分母是不是正的常数** —— `N/D` 的符号取决于 `D`，不能只看 `N`。

## 与相邻模块的分工

| 想要的东西 | 用哪个 | 为什么 |
| --- | --- | --- |
| `√(x²+1)` | `radical` | 独立根式的和，塔是它的**严格更弱**的特例 |
| `√(1+√x)` | **`tower`** | radical 表示不了 |
| `√(x²)` | `piecewise` | 那是 `\|x\|`，代数函数域装不下（`y²−x²` 可约） |

判断顺序在 `src/parser/parser.cppm` 的 `parseTowerExpression`：先试单层的
`parseRadicalExpression`，失败再上塔。

## 已知限制

- **判等只保证「值相等」，不保证「形式相等」**：`1/√x` 与 `√x/(√x·√x)` 代数上是同一个
  函数，但作为「平表之比」是两种形式（不做规范化约分）
- 多元的符号判定**做不到**（需要多元多项式不等式求解，即 CAD）——
  但这**不影响多元绝对值**：`MultiPiecewiseFunction` 的分支定义域就是符号本身
  （`|f|` = `{f : {f≥0}, −f : {f<0}}`），表示与判定是两件事
